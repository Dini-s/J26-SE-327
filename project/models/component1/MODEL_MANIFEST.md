# Component 1 model manifest

What each file under `models/component1/` is, which one the requirement agent loads, and how it scored.

- **Scores** are macro-F1 on the **frozen test split** with 95 % bootstrap CIs (1000 resamples) in brackets, copied from `evaluation/component1/results/RESULTS.md` (the rerun after the one-row train correction). Seed 327. Models were fitted on train and tuned on val only.
- **Slice**: the pooled test row of each task unless a different slice is named. The multi-label PROMISE subtype task has only 43 test rows, so its CIs are wide.
- **Loaded by agent**: `yes` means `agents/requirement_agent/agent.py` loads the file from `part_a_active/` (`MODELS_DIR` and `MODEL_FILES`, and `load_models`). The 21 files in `part_a_experiments/` (`fr_nfr/`, `security_and_subtype/`, `ambiguity/`) are baselines kept for comparison; the agent never loads them.
- **Layout note**: `python -m evaluation.run_baselines` writes to `part_a_experiments/<group>/`; the active copies in `part_a_active/` are refreshed manually (copy the file you want).
- Algorithms: `majority` = most frequent class; `rules` = hand-written keyword rules (no learning); `tfidf_lr` = word 1-2-gram TF-IDF + logistic regression (balanced class weights); `tfidf_svm` = same TF-IDF + linear SVM; `emb_lr` = frozen `all-MiniLM-L6-v2` sentence embeddings + logistic regression; `qure_weak_word_rule` = regex over the QuRE weak-word list.
- The agent output is a triage hint (`boundary_status=auto_unverified`); these are baselines, not production-grade classifiers.

### Duplicates note

**The duplicates F1 of 0.853 is on seeded pairs only.** It is the best F1 on 3000 rule-made *development* pairs from the train split, where the threshold was chosen (`dev_f1` in `duplicates_config.json`, CI [0.837, 0.869]). The pairs are generated by rule edits (case/punctuation, dropped modifier, modal swap, trailing clause, clause reorder) and swapped-word hard negatives; they are not human-labelled duplicates and the frozen test split is not used. On the 1500 held-out seeded pairs from the val split the result is lower: F1 0.812 [0.784, 0.837] with hard negatives (precision 0.716, recall 0.938), and 0.968 [0.956, 0.979] with easy negatives only. Recall on real paraphrases is unknown (`evaluation/component1/results/duplicates_eval/DUPLICATES_EVAL.md`).

## Reading the scores

- Frozen-test, grouped-CV, stratified-CV and leave-one-project-out numbers in `RESULTS.md` are different estimates; only frozen-test is quoted here.
- FR/NFR: `tfidf_svm` and `tfidf_lr` beat `emb_lr` on the frozen test, but the agent uses `emb_lr` (it is the best under PROMISE leave-one-project-out, 0.798 vs 0.641-0.654).
- The ambiguity detector is weak across sources (cross-source rows 0.37-0.49); treat `ambiguity_label` as a hint.
- Cross-source ambiguity macro-F1 for the models the agent does not load is listed for reference only.
