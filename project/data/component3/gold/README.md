# Component 3 Gold-Standard Labels

This directory contains reference labels used for
empirical evaluation.

Labels must not be inferred from the implementation
being evaluated.

Where expert review is required, reviewer identity,
review date, notes, disagreement resolution, and
adjudicated labels should be recorded.

## retrieval_gold.json

Expected item shape:

```json
{
  "rvu_id": "REQ-PET-001-RVU-01",
  "relevant_evidence_ids": ["MT-001"]
}
```
